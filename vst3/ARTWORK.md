# Artwork

`vst3/hero.jpg` is the panel reference image. It is the author's reference
artwork and is **not** covered by the MIT license that applies to the code.

If you fork this project and do not own the image, replace `vst3/hero.jpg`
with your own picture and regenerate `vst3/hero_image.h` (any JPEG-to-C-array
tool works; the array is `jm::kHeroJpg` plus `jm::kHeroJpgSize`).
